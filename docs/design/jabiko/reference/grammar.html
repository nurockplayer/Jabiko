N3高頻

〜みたいだ

好像…（依自己看到、聽到的判斷）

見たり聞いたりしたことから判断する

接續

動詞・い形容詞
普通形 ＋ みたいだ
な形容詞・名詞
語幹 ／ 名詞 ＋ みたいだ

例句

電車、止まってるみたいですね。

電車好像停了耶。

外は雨が降っているみたいだ。

外面好像在下雨。

常見錯誤

「みたいだ」是口語；正式文章多用「ようだ」。

上一個〜ばかり下一個〜わけがない

相關文型

〜ようだ好像（書面） 〜らしい聽說、像是 〜そうだ看起來
