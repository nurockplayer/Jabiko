短 · 同事 / 同事 · です・ます

夏天早上，你和同事剛走進公司，對方提起外面的熱氣。

  1. 同事

    今日きょうも暑あついですね。駅えきから歩あるくだけで汗あせをかいちゃいました。

  2. 你

    そうですね。暑あついですね。

你的回應

回應同事，試著留下一個可以接話的線索。

這樣回，對方接得下去嗎？

這是自然的附和，並沒有說錯。以這次「延續話題」的目標來看，它還沒有提供新的接話線索。

  • 聽得懂做到了

    意思清楚。

  • 正確做到了

    文法與用字正確。

  • 自然做到了

    日本人也常這樣附和。

  • 接得下去可以再加強

    對方只能回「そうですね」，話題容易停住。

  • 場合語氣做到了

    對同事用です・ます剛好。
