て形

動詞のて形

て形用來連接動作、請求別人做事，也是很多文型的基礎。變化方式依動詞分類而不同：第一類動詞看字尾，第二類去掉「る」加「て」。

書く → 書いて　読む → 読んで　食べる → 食べて

例句

朝ごはんを食べて、学校に行きます。

吃完早餐，然後去學校。

ちょっと待ってください。

請稍等一下。

常見陷阱

  1. 行く 是例外：行って，不是 行いて。
  2. 第一類動詞字尾 む・ぶ・ぬ 都變成 んで。
