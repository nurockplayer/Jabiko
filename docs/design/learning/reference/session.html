正解Correct 答錯Not quite 答案Answer shown 正解：Answer: つごう N3

「都」在此讀「つ」、「合」濁化讀「ごう」，故「都合」＝つごう（情況、方便與否）。「とごう」誤把「都」讀成「と」；「つこう」漏掉「合」的濁音；「とこう」兩處都錯。 Here 「都」 is read 「つ」 and 「合」 voices to 「ごう」, so 「都合」＝つごう (circumstances; convenience). 「とごう」 wrongly reads 「都」 as 「と」; 「つこう」 drops the voicing on 「合」; 「とこう」 gets both wrong.
