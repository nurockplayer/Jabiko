〜に違いない

N3高頻

一定是～、肯定～

〜に決まっている／強い推測

接續
動詞・形容詞普通形＋に違いない；名詞＋に違いない

接續與中文解釋僅在繁體中文介面顯示（語言隔離規則）；其他語言顯示 meaningJa 與 i18n 覆寫內容。

例句

  • あの人は日本人に違いない。那個人一定是日本人。
