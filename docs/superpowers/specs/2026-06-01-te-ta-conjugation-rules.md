# て形 / た形變化規則

## 目的

記錄日文動詞 `て形` 與 `た形` 的第一版實作規則。練習網站應該在 domain conjugation module 產生答案，並在學習者答錯時顯示容易理解的台灣正體中文規則說明。

## 範圍

- 僅限動詞的目標形：
  - `te`: て形
  - `ta`: た形
  - `plainPastAffirmative`: 普通形・過去肯定，由 `た形` 產生
- 涵蓋動詞分類：
  - 一類動詞 / godan
  - 二類動詞 / ichidan
  - 三類動詞 / irregular，包含 `する`、`来る` 與 `名詞 + する`

## 一類動詞規則表

一類動詞要依辭書形最後一個假名，換成對應的 `て形` 或 `た形` 音便語尾。

| 最後假名 | て形語尾 | た形語尾 | 例子 |
| --- | --- | --- | --- |
| う | って | った | 買う -> 買って / 買った |
| つ | って | った | 待つ -> 待って / 待った |
| る | って | った | 帰る -> 帰って / 帰った |
| む | んで | んだ | 飲む -> 飲んで / 飲んだ |
| ぶ | んで | んだ | 遊ぶ -> 遊んで / 遊んだ |
| ぬ | んで | んだ | 死ぬ -> 死んで / 死んだ |
| く | いて | いた | 書く -> 書いて / 書いた |
| ぐ | いで | いだ | 泳ぐ -> 泳いで / 泳いだ |
| す | して | した | 話す -> 話して / 話した |

`行く` 是初級必背例外：`行って` / `行った`，不是 `行いて` / `行いた`。

## 二類動詞規則

二類動詞先去掉最後的 `る`，再接 `て` 或 `た`。

- 食べる -> 食べて / 食べた
- 見る -> 見て / 見た

## 三類動詞規則

三類動詞以明確的不規則表處理。

- する -> して / した
- 勉強する -> 勉強して / 勉強した
- 来る -> 来て / 来た

## 說明文字需求

學習回饋需要明確指出套用的規則：

- `て形` 與 `た形` 要說明一類動詞使用音便。
- `plainPastAffirmative` 要說明它和 `た形` 是同一組變化，因為普通形・過去肯定就是 `た形`。
- `plainPastAffirmative` 的說明不能 fallback 成 `ます形` 規則。
