# 學習追蹤與個人化複習系統提案

## 啟發來源
根據對專案架構和功能的分析，識別出提升學習效果的機會。

## 問題描述
目前專案具備基本的詞彙、語法練習功能以及錯誤題目補強機制，但缺乏系統化的學習進度追蹤和基於個人學習歷史的智能複習建議。

## 建議功能
1. **間隔重複系統 (SRS) 強化**
   - 基於現有的錯誤題目記錄，實踐更完整的間隔重複演算法
   - 參考 Leitner 系統或類似 Anki 的間隔算法
   - 根據詞彙/語法點的掌握程度動態調整複習間隔

2. **學習分析儀表板**
   - 顯示學習進度（已學詞彙數、掌握程度分布等）
   - 學習時間統計和趨勢圖
   - 弱點分析（哪些詞彙/語法點需要更多練習）

3. **智能練習推薦**
   - 基於學習歷史和間隔重複算法，智能選擇當天應複習的內容
   - 優先推薦即將遺忘的知識點
   - 平衡新學內容與溫故內容的比例

4. **學習目標與提醒**
   - 設置每日目標（例如：學習 10 個新詞彙，複習 20 個舊詞）
   - 達標通知和成就系統
   - 學習連續天數追蹤

## 技術實現建議
- 在 `src/domain/` 中擴充學習追蹤相關領域模型（`learningStats.ts`, `srsAlgorithm.ts`等）
- 利用現有的 Supabase 整合來持久化學習資料
- 在 `src/hooks/` 中開發自定義 Hook 來封裝學習邏輯
- 考慮使用 Context API 或狀態管理庫來共享學習狀態

## 優先級建議
中等至高優先級 - 這將顯著提升應用程式的學習效果和用戶留存率，與日語學習應用的核心價值直接相關。

## 參考現有功能
- 建立於現有錯誤題目補強功能（參考 issue #109 和 #118）
- 與詞彙系統（vocabulary.ts, vocabulary-jlpt.ts）整合
- 利用現有的 Supabase 認證基礎設施

## 成功指標
- 用戶平均學習時長增加
- 錯誤題目復習後正確率提升
- 日活用戶留存率提升
