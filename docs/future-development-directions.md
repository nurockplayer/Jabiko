# Jabiko 專案未來發展方向

## 概述
本文件記錄了針對 Jabiko 專案（給《大家的日本語》學習者使用的日文變化練習網站）的潛在未來發展方向，基於專案現有架構和技術棧進行分析。

## 目前專案狀態
Jabiko 是一個專注於「大家的日本語」初級文法練習的網站，目前已實施：
- 動詞一二三類、普通形、辭書形、否定形、過去、て形、た形等基本變化練習
- 形容詞變化練習
- Supabase Google 登入功能（最新功能）
- 考試系統與錯題複習機制
- 練習紀錄（LocalStorage）
- 領域驅動設計：`src/domain/`（商業邏輯）、`src/components/`（React UI）、`src/hooks/`
- 技術棧：React 19 + TypeScript strict mode + Vite 7 + Vitest 4 + jsdom + pnpm

## 未來發展方向

### 1. 深化學習系統
#### 間隔重複系統（SRS）強化
- 基於現有的錯誤題目記錄，實踐更完整的間隔重複演算法
- 參考 Leitner 系統或類似 Anki 的間隔算法
- 根據詞彙/語法點的掌握程度動態調整複習間隔
- 技術實現：在 `src/domain/` 中新增 `srsAlgorithm.ts`、`learningStats.ts`

#### 學習分析儀表板
- 顯示學習進度（已學詞彙數、掌握程度分布等）
- 學習時間統計和趨勢圖
- 弱點分析（哪些詞彙/語法點需要更多練習）
- 學習模式分析（學習時間、頻率等）

#### 智能練習推薦
- 基於學習歷史和間隔重複算法，智能選擇當天應複習的內容
- 優先推薦即將遺忘的知識點
- 平衡新學內容與溫故內容的比例
- 自適應難度調整

#### 學習目標與提醒
- 設置每日目標（例如：學習 10 個新詞彙，複習 20 個舊詞）
- 達標通知和成就系統
- 學習連續天數追蹤
- 視覺化進度條和里程碑

### 2. 內容擴充
#### 詞彙庫擴充
- 擴充 `vocabulary.ts` 和 `vocabulary-jlpt.ts` 以包含更多詞彙
- 添加例句、圖片、發音標註
- 按 JETST、JLPT 等級分類
- 加入詞源說明和聯想記憶法

#### 文法點擴展
- 超越基本變化，加入更複雜的文法點：
  - 使役形、被動形
  - 敬語（尊敬語、謙譲語、丁寧語）
  - 縮約形（～てる、～てしまう等）
  - 複合句結構
  - 語氣詞和禮貌表達

#### 實用會話情境
- 添加情境對話練習（購物、餐廳、交通、醫院等場景）
- 情境單字學習
- 文化背景說明
- 聽力理解練習

### 3. 技術與使用體驗改進
#### 離線功能
- 利用 Service Worker 和 IndexedDB 實現真正的離線學習
- 進度同步機制（上線時自動同步）
- 零狀態設計（離線時也能進行基本練習）

#### 進階統計與分析
- 詳細的學習分析儀表板：
  - 學習時間分布（按日期、時間段）
  - 知識點掌握度熱力圖
  - 錯誤類型分析（形態錯誤、意思錯誤等）
  - 學習效率趨勢
  - 與目標的對比分析

#### 社群功能
- 學習小組或學習夥伴系統
- 進度分享和成就展示（可選擇性公開）
- 互相挑戰和排名（友好競爭）
- 學習心得和筆記分享

#### 多媒體增強
- 語音發音（使用 Web Speech API 或預錄音檔）
- 影片說明複雜文法點
- 互動圖表和視覺化說明
- 動詞活用動畫展示

#### 響應式設計優化
- 改進行動裝置體驗
- PWA（Progressive Web App）功能
- 離線快取和資源預載
- 觸摸友好的互動元件

### 4. 評量與回饋系統
#### 模擬考試
- 完整的 JLPT 模擬考或「大家的日本語」單元測驗
- 計時模式和正式考試模擬
- 自動評分和詳細回饋
- 錯誤題目自動加入複習隊列

#### 即時語法錯誤訂正
- 除了對錯之外，提供具體的錯誤說明和正確解釋
- 錯誤類型標籤（詞形錯誤、助詞錯誤、時態錯誤等）
- 相似錯誤範例展示
- 一點擊查看相關語法規則

#### 語音辨識練習
- 利用 Web Speech API 進行發音練習
- 閱讀句子或單詞的發音評分
-  Tone and pitch 調整建議
- 對比母語者發音

#### 寫作練習
- 簡單的句子組成或寫作練習
- 基本的語法檢查和建議
- 範例答案參考
- 逐步改進提示

### 5. 技術架構優化
#### 狀態管理優化
- 評估使用 Zustand、Jotai 或 Redux Toolkit 替代散落的 useState/useContext
- 集中狀態存儲以改善調試和測試
- 擴充狀態持久化策略

#### 效能優化
- React Memo、useMemo、useCallback 的更精細應用
- 代碼分割和延遲載入
- 圖片和資源優化
- 懶加載非關鍵組件

#### 測試覆蓋率提升
- 複雜領域邏輯的單元測試和整合測試
- 邊界案例測試
- UI 元件測試與使用者互動模擬
- 無障礙測試（a11y）

#### 國際化（i18n）完善
- 更系統化的多語言實現
- 添加更多語言選項（日文原文、越南文、泰文等）
- 語言切換持久化
- 日期、數字格式本地化

### 6. 與外部資源整合
#### 詞典API整合
- 整合線上詞典服務（如 Jisho.org、Weblio）
- 單擊詞彙查詢詳細定義和例句
- 語源和用法說明
- 相關詞彙推薦

#### 日語新聞簡報
- 簡易的日讀新聞閱讀練習
- 按難度分級的新聞摘要
- 生詞標註和翻譯功能
- 文化背景解說

#### 語法解說連結
- 連結到權威的日語學習資源
- Tae Kim's Guide、日本語の森、 laissaitalk 等
- 主題相關的學習資源推薦
- 線上練習題目鏈接

## 技術實現建議

### 優先級建議
**高優先級：**
1. 間隔重複系統強化（直接提升學習效果）
2. 離線功能（提升使用場景和便利性）
3. 基礎統計與分析（了解學習情況）

**中等優先級：**
4. 內容擴充（詞彙和文法點）
5. 技術架構優化（維護性和擴展性）
6. 評量與回饋系統改進

**長期發展：**
7. 社群功能
8. 多媒體增強
9. 外部資源整合
10. 高級分析和預測

### 實現路徑
1. **短期（1-3個月）**：
   - 完成 SRS 算法實現
   - 加強錯誤題目追蹤和分析
   - 基礎離線功能（緩存已學內容）

2. **中期（3-6個月）**：
   - 完整學習分析儀表板
   - 內容擴充（JLPT N4-N3 級詞彙）
   - 基礎評量系統改進

3. **長期（6-12個月+）**：
   - 社群功能和多媒體增強
   - 高級評量系統（口語、寫作）
   - 外部資源整合和合作

### 技術棧考量
- 保持現有技術棧一致性（React + TypeScript + Vite）
- 利用現有 Supabase 後端基礎設施
- 漸進式增強：新功能不破壞現有核心功能
- 保持領域驅動設計原則：業務邏輯集中於 `src/domain/`

## 成功指標
- 用戶平均學習時長增加 30%+
- 錯誤題目複習後正確率提升 40%+
- 日活用戶留存率（7-day retention）提升 25%+
- 用戶滿意度評分 4.5/5+
- 付費轉換率（如適用）達到業界平均水準

## 與現有功能的關聯
這些發展方向均建基於現有功能：
- 建立於現有錯誤題目補強功能（參考 issue #109 和 #118）
- 與詞彙系統（vocabulary.ts, vocabulary-jlpt.ts）整合
- 利用現有的 Supabase 認證基礎設施
- 保持領域驅動架構：新功能核心邏輯放於 `src/domain/`
- UI 變更遵循現有元件模式：`src/components/` 擴展

2. 為選定功能創建詳細規劃文件（使用 GSD 方法論）
3. 設定開發里程碑和驗收標準
4. 開始實施第一個增強功能的迭代開發
